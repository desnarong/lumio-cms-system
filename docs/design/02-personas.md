# 02 — กลุ่มผู้ใช้ (Personas)

## 2.1 Persona หลัก

| Persona | ต้องการ | สิ่งที่ Lumio ต้องให้ | ตัวชี้วัดที่เกี่ยวข้อง |
|---|---|---|---|
| **แม่ค้าออนไลน์ / ร้านเล็ก** | เว็บร้าน + ติดต่อ + LINE | Template ร้านค้า, ปุ่ม LINE/โทร, แผนที่ | Publish ภายใน 24 ชม. |
| **ฟรีแลนซ์ / ครีเอเตอร์** | Portfolio, บล็อก | Template สวย, gallery, blog | Retention 30 วัน |
| **ธุรกิจ SME** | เว็บบริษัท, ฟอร์มติดต่อ, SEO | หลายหน้า, ฟอร์ม, SEO, หลายภาษา | Onboarding completion |
| **เอเจนซี่ / นักพัฒนา** | ทำเว็บให้ลูกค้าหลายราย | Multi-site, white-label, API, Custom blocks | จำนวนเว็บต่อบัญชี |
| **ผู้ดูแลเนื้อหา (Editor)** | เขียนบทความ | Editor เรียบง่าย สิทธิ์จำกัด | จำนวนบทความ/เดือน |

## 2.2 Jobs-to-be-done (งานที่ผู้ใช้ต้องทำ)

เขียนในมุม "เมื่อ... ฉันอยาก... เพื่อ..."

| เมื่อ... | ฉันอยาก... | เพื่อ... |
|---|---|---|
| เปิด Lumio ครั้งแรก | เห็นเว็บตัวอย่างที่ใกล้ธุรกิจตัวเอง | ไมต้องเริ่มจากกระดาษเปล่า |
| เห็นข้อความผิดบนหน้าเว็บ | แก้ได้ตรงนั้นเลย | ไม่ต้องหาว่ามันอยู่เมนูไหน |
| อยากเพิ่มหน้าใหม่ | เลือกจาก template ที่มีอยู่แล้ว | ไม่ต้องออกแบบ layout เอง |
| อยากเปลี่ยนสีทั้งเว็บ | เปลี่ยนที่เดียวแล้วเห็นผลทุกหน้า | ไม่ต้องแก้ทีละหน้า |
| กลัวทำพัง | กด Undo หรือย้อนเวอร์ชัน | กล้าลองของใหม่ |
| เผลอกดลบ | กู้คืนได้ทันที | ไม่เสียข้อมูล |
| ทำเสร็จแล้ว | กด Publish แล้วได้ลิงก์แชร์ | เอาไปใช้ได้เลย |

## 2.3 ความต้องการเฉพาะต่อ Persona

### แม่ค้าออนไลน์ / ร้านเล็ก
- **ต้องมี**: ปุ่มโทร/LINE ลอย, แผนที่, gallery สินค้า, ฟอร์มสั่งซื้อ/สอบถาม
- **ปวดหัวกับ**: ศัพท์เทคนิค (Slug, Post type, Widget) → ใช้คำธุรกิจ
- **งานหลัก**: เปลี่ยนรูปสินค้า, เพิ่มโปรโมชัน, ตอบข้อความลูกค้า

### ฟรีแลนซ์ / ครีเอเตอร์
- **ต้องมี**: Portfolio gallery, blog, social links, ปุ่มติดต่อ
- **ปวดหัวกับ**: ธีมที่ปรับแล้วพัง, layout ที่ไม่ responsive
- **งานหลัก**: อัปโหลดผลงาน, เขียนบทความ, แชร์ลิงก์บนโซเชียล

### ธุรกิจ SME
- **ต้องมี**: หลายหน้า, ฟอร์มติดต่อ, SEO score, หลายภาษา, ทีมงาน
- **ปวดหัวกับ**: SEO ที่ต้องลง plugin, ฟอร์มที่ต้องพึ่ง third-party
- **งานหลัก**: อัปเดตบริการ, ดูแล SEO, มอบหมายงานให้ทีม

### เอเจนซี่ / นักพัฒนา
- **ต้องมี**: multi-site dashboard, white-label, API, webhooks, custom block
- **ปวดหัวกับ**: ต้อง login/logout สลับหลายบัญชี, ต้องตั้งค่าซ้ำทุกเว็บ
- **งานหลัก**: สร้างเว็บให้ลูกค้า, ส่งมอบ, ดูแลต่อ

### ผู้ดูแลเนื้อหา (Editor)
- **ต้องมี**: editor เรียบง่าย, draft/ส่งตรวจ, สิทธิ์จำกัด (ไม่แตะ design/domain)
- **ปวดหัวกับ**: เมนูเยอะเกิน, กลัวกดพลาดของสำคัญ
- **งานหลัก**: เขียน/แก้บทความ, ใส่รูป, ตั้งหมวดหมู่

## 2.4 บทบาทและสิทธิ์

Persona ≠ Role แต่สัมพันธ์กัน — ดูตารางสิทธิ์เต็มที่ [13-rbac.md](13-rbac.md)

| Persona | Role เริ่มต้น |
|---|---|
| แม่ค้า / ฟรีแลนซ์ (เจ้าของเว็บ) | Owner |
| SME (ผู้ดูแล) | Admin |
| Editor (พนักงาน) | Editor / Author |
| เอเจนซี่ | Owner หลายเว็บ (multi-site) |
| ลูกค้าของเอเจนซี่ | Admin (จำกัด) |

## 2.5 วิธีทดสอบ Persona (ก่อนปล่อยจริง)

ให้คนที่ไม่เคยทำเว็บ **5 คน** (อย่างน้อย 1 คนต่อ 1 persona หลัก) ทำภารกิจนี้โดยไม่มีคนช่วย:

1. เปลี่ยนข้อความหัวเว็บ
2. เปลี่ยนรูป
3. เพิ่มหน้าใหม่
4. เปลี่ยนสีหลัก
5. Publish

**เกณฑ์ผ่าน**: ทุกคนทำครบทั้ง 5 ข้อได้เอง ถ้ามีใครติด → กลับไปแก้ UI (ไม่ใช่แก้คู่มือ)
