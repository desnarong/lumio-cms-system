# 05 — Admin Information Architecture

## 5.1 เมนูหลัก (5 เมนูเท่านั้น)

Sidebar ซ้าย (เดสก์ท็อป) / Bottom bar (มือถือ):

```
🏠 ภาพรวม (Dashboard)
📄 เนื้อหา (Content)
    ├─ หน้าเว็บ
    ├─ บทความ
    ├─ ฟอร์ม & ข้อความที่ได้รับ
    └─ ไฟล์สื่อ (Media)
🎨 ดีไซน์ (Design)
    ├─ สไตล์ (สี/ฟอนต์/ปุ่ม)
    ├─ เมนูนำทาง
    ├─ Header / Footer
    └─ เปลี่ยน Template
📈 เติบโต (Growth)
    ├─ SEO
    ├─ Analytics
    ├─ Newsletter
    └─ Apps (เสริม)
⚙️ ตั้งค่า (Settings)
    ├─ ทั่วไป / โดเมน
    ├─ ทีมงาน & สิทธิ์
    ├─ Backup & ประวัติเวอร์ชัน
    └─ แพ็กเกจ & การชำระเงิน
```

### เหตุผลที่แต่ละเมนูอยู่ตรงนี้

| เมนู | คำถามที่ตอบให้ผู้ใช้ |
|---|---|
| ภาพรวม | "ตอนนี้เว็บเป็นยังไง ต้องทำอะไรต่อ" |
| เนื้อหา | "แก้/เพิ่มเนื้อหา" |
| ดีไซน์ | "ทำเว็บให้สวย" (ไม่ต้องเขียนโค้ด) |
| เติบโต | "ทำให้คนเจอเว็บมากขึ้น" |
| ตั้งค่า | "จัดการเว็บ โดเมน ทีม เงิน" |

### กติกา IA
- **ห้ามเพิ่มเมนูหลักที่ 6** — ถ้าฟีเจอร์ใหม่มา ให้ซ่อนในเมนูที่มีอยู่ หรืออยู่ใน Apps
- เมนูย่อยใช้ label ภาษาธุรกิจ (ดู [04.5](04-ux.md#45-กฎ-ux-ที่ต้องรักษา))
- เมนูที่ผู้ใช้ role นั้นเข้าไม่ได้ → **ซ่อน** (ไม่ใช่ disable) เพื่อลดความสับสน

## 5.2 Dashboard

การ์ดเรียบง่าย 4 ส่วน:

1. **ปุ่มลัด**: ✏️ แก้เว็บ · ＋ หน้าใหม่ · ✍️ เขียนบทความ · 👁 ดูเว็บ
2. **สถิติวันนี้**: ผู้เข้าชม, ข้อความใหม่, ยอดสมัครรับข่าว (พร้อมกราฟเส้นเล็ก)
3. **คะแนนสุขภาพเว็บ** (วงกลม 0–100) + "3 สิ่งที่ควรแก้" (กดแล้วไปแก้ได้เลย)
4. **Checklist เริ่มต้น** (หายไปเมื่อครบ)

### หลักการของ Dashboard
- **ทุกการ์ดต้องกดแล้วทำต่อได้** — ห้ามมีข้อมูลที่ดูได้อย่างเดียวโดยไม่มีทางแก้
- สถิติแสดง **แนวโน้ม** (↑/↓ %) ไม่ใช่แค่ตัวเลขดิบ
- "3 สิ่งที่ควรแก้" มาจาก SEO score + checklist + alt ที่ขาด (เรียงตามผลกระทบ)
- โหลดเร็ว: ใช้ skeleton ทันที, ดึงข้อมูลแบบขนาน

## 5.3 Responsive Admin

| ความกว้าง | Sidebar | รูปแบบ |
|---|---|---|
| ≥ 1024px | เต็ม (240px) | sidebar + content |
| 768–1023px | ย่อ (72px, ไอคอน) | sidebar ย่อ + content |
| < 768px | Bottom bar | bottom nav 5 ปุ่ม + content เต็มจอ |

- บนมือถือ **แก้ไขเว็บได้จริง** (ไม่ใช่ดูได้อย่างเดียว)
- Editor บนมือถือใช้ bottom sheet แทน side panel

## 5.4 Navigation ภายใน Content

- ทุกหน้ารายการ (list) มี: ค้นหา, กรองตามสถานะ (draft/published), เรียง, bulk action
- ใช้ pagination แบบ cursor (ไม่ใช้เลขหน้า)
- Breadcrumb เฉพาะเมื่อลึก ≥ 2 ชั้น
