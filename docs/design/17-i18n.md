# 17 — หลายภาษา (i18n)

## 17.1 แนวคิด

- เลือกภาษาหลัก + ภาษาเสริม ตอนตั้งค่า
- หน้าแต่ละภาษาเป็น record แยก (`locale`) เชื่อมกันด้วย `translation_group_id`
- ปุ่ม **✨ แปลหน้านี้ด้วย AI** → ได้ draft ภาษาใหม่ให้ตรวจ
- Language switcher block + hreflang อัตโนมัติ
- URL: `/en/about`, `/th/about` (หรือ subdomain/domain ต่อภาษา)

## 17.2 โครงสร้างข้อมูล

เพิ่มคอลัมน์ใน `contents`:

```sql
ALTER TABLE contents ADD COLUMN translation_group_id UUID;
CREATE INDEX idx_contents_translation ON contents (translation_group_id, locale);
```

- หน้าเดียวกันคนละภาษา = คนละ row, `translation_group_id` เดียวกัน
- `UNIQUE (site_id, locale, type, slug)` ยังคงอยู่ (slug ซ้ำได้ข้ามภาษา)

## 17.3 UI ที่ต้องมี

| จุด | พฤติกรรม |
|---|---|
| ตัวสลับภาษา (admin) | เห็นว่าภาษาไหนมีแล้ว/ยังไม่มี (badge) |
| สร้างคำแปล | คัดลอกโครง block แล้วแปลข้อความ → draft |
| แปลส่วนที่เหลือ | แปลเฉพาะข้อความที่ยังเหมือนภาษาต้นฉบับในหน้านั้น (กดซ้ำได้ ไม่ทับของที่แปลแล้ว) |
| ตัวกรองภาษา | รายการหน้าเว็บ/บทความกรองตามภาษาได้ พร้อมป้ายภาษาต่อแถว |
| Language switcher block | ผู้ชมสลับภาษาบนเว็บ |
| hreflang | เจนอัตโนมัติใน `<head>` |

## 17.4 กติกา

1. ข้อความ UI ทุกตัวผ่าน i18n (th เป็นค่าเริ่มต้น, en เสริม) — ดู [AGENTS.md](../../AGENTS.md)
2. เนื้อหาผู้ใช้ไม่บังคับแปล — แปลเฉพาะที่ผู้ใช้สั่ง
3. AI แปลต้องออกมาเป็น **draft** ให้ตรวจเสมอ
4. ถ้าหน้าไหนไม่มีคำแปล → fallback ไปภาษาหลัก + แสดงป้าย
5. URL/hreflang/canonical ต้องสอดคล้องกัน (canonical ชี้ภาษาตัวเอง, hreflang ชี้ทุกภาษา)

## 17.5 การทดสอบ

- สลับภาษาแล้วเนื้อหา/เมนู/ฟอร์มเปลี่ยนตาม
- hreflang ครบทุกภาษาที่มี
- หน้าไม่มีคำแปล → fallback ถูกต้อง
- slug ไม่ชนกันข้ามภาษา
