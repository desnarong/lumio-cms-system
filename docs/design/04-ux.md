# 04 — ประสบการณ์ผู้ใช้ (UX)

## 4.1 Onboarding Wizard (5 ขั้นตอน ≤ 3 นาที)

```
 ① ธุรกิจคุณคืออะไร?     → [ร้านอาหาร] [คลินิก] [ฟรีแลนซ์] [ร้านค้า] [บล็อก] [อื่นๆ]
 ② ตั้งชื่อเว็บ + อัปโหลดโลโก้ (ข้ามได้)
 ③ เลือกสไตล์            → 6 การ์ดตัวอย่าง (Minimal / Bold / Soft / Elegant ...)
 ④ เลือกสีหลัก           → พาเลทสีสำเร็จรูป หรือดึงสีจากโลโก้อัตโนมัติ
 ⑤ ✨ สร้างเว็บให้เลย!    → ได้เว็บ 4-5 หน้าพร้อมเนื้อหาตัวอย่าง (AI ช่วยเติมตามประเภทธุรกิจ)
```

### รายละเอียดแต่ละขั้น

| ขั้น | สิ่งที่เกิดขึ้นเบื้องหลัง | ทางเลือก |
|---|---|---|
| ① ประเภทธุรกิจ | เก็บ `business_type` → ใช้เลือก template + AI prompt | ข้ามได้ (เลือก "อื่นๆ") |
| ② ชื่อ + โลโก้ | สร้าง `site`, จอง subdomain, สร้าง favicon จากโลโก้ | ข้ามโลโก้ได้ |
| ③ สไตล์ | เลือก token set (สี/ฟอนต์/มุมโค้ง) | มี preview สด |
| ④ สีหลัก | สร้างพาเลทจากสีเดียว (tints/shades) หรือดึงจากโลโก้ | มี contrast checker |
| ⑤ สร้างเว็บ | สร้าง 4–5 หน้าจาก template + AI เติมข้อความ | ใช้เวลา ≤ 30 วินาที |

หลังจบ wizard ผู้ใช้เข้าสู่ **โหมดแก้ไขหน้าเว็บ** ทันที พร้อม tooltip นำทาง 3 จุด
และ **Checklist เริ่มต้น** (แบบ "เริ่มต้นใช้งาน 4/6 เสร็จแล้ว") ที่หายไปเมื่อทำครบ

### Checklist เริ่มต้น (6 ข้อ)
1. ✓ ตั้งชื่อเว็บ
2. ✓ เลือกสไตล์
3. ○ เปลี่ยนข้อความหน้าแรก
4. ○ อัปโหลดรูป
5. ○ เชื่อมโดเมน
6. ○ กด Publish ครั้งแรก

## 4.2 Edit on Page (หัวใจของระบบ)

- ผู้ใช้เปิดหน้าเว็บแล้วเห็น **แถบเครื่องมือลอย** ด้านบน (Edit / Design / Pages / Publish)
- **คลิกข้อความ = พิมพ์แก้ได้เลย**, คลิกรูป = เปลี่ยนรูป, คลิกปุ่ม = ตั้งลิงก์
- เอาเมาส์ชี้ระหว่าง block จะมีปุ่ม **＋** เพิ่ม block ใหม่
- ชี้ที่ block จะมี handle **⋮⋮** ลากเรียงลำดับ + เมนูย่อ (ทำซ้ำ, ซ่อน, ลบ, บันทึกเป็นเทมเพลต)
- พิมพ์ `/` เพื่อเรียกรายการ block (แบบ Notion)
- **Responsive Toggle** 📱💻🖥 สลับมุมมองมือถือ/แท็บเล็ต/เดสก์ท็อป
- **Undo / Redo ไม่จำกัด** (Ctrl+Z) + Autosave ทุก 2 วินาที
- ปุ่ม **Publish** สีเด่นมุมขวาบน (เห็นสถานะ: ● Draft / ✓ Published)

### พฤติกรรมสำคัญ (ต้องเทสต์)

| การกระทำ | ผลที่ต้องเกิด |
|---|---|
| คลิกข้อความ | เข้า inline edit, cursor วางถูกตำแหน่ง |
| กด Esc | ออกจาก edit โดยไม่บันทึก |
| ลาก block | เห็น drop indicator, ปล่อยแล้วเรียงใหม่ทันที |
| กด Ctrl+Z หลังลบ block | block กลับมาในตำแหน่งเดิม |
| ปิดแท็บระหว่างแก้ | draft ถูก autosave ไว้ (กู้คืนได้) |
| Publish ขณะ autosave ค้าง | รอ save เสร็จก่อน publish (ห้าม publish draft เก่า) |

## 4.3 Command Palette (`Ctrl/⌘ + K`)

พิมพ์ค้นหาอะไรก็ได้: "เพิ่มหน้าใหม่", "เปลี่ยนสีหลัก", "ไปที่รูปภาพ", "ตั้งโดเมน" → ไปถึงทันที

- ค้นหาทั้ง **action** (คำสั่ง) และ **content** (หน้า/บทความ/รูป)
- แสดง recent + suggested เมื่อยังไม่พิมพ์อะไร
- ใช้ fuzzy match + รองรับภาษาไทย

## 4.4 ระดับความซับซ้อน 3 ชั้น

| ระดับ | ผู้ใช้เห็น |
|---|---|
| **Simple** (ค่าเริ่มต้น) | แก้ข้อความ รูป สี ปุ่ม เท่านั้น |
| **Pro** | Spacing, animation, custom CSS class, visibility ตามอุปกรณ์ |
| **Developer** | Custom CSS/JS, Code block, API keys, Webhooks |

สลับได้ที่ Settings > Mode — ผู้เริ่มต้นจะไม่เห็นตัวเลือกซับซ้อนเลย

**กติกา**: ทุก panel ต้องจัดกลุ่ม "เนื้อหา / หน้าตา / ขั้นสูง" และซ่อน "ขั้นสูง" ไว้ในโหมด Pro ขึ้นไป

## 4.5 กฎ UX ที่ต้องรักษา

- ทุกการกระทำสำคัญต้อง **ยกเลิกได้** (Toast "ลบแล้ว — [เลิกทำ]" แทน Confirm dialog)
- ข้อความ error เป็นภาษาคน เช่น "รูปใหญ่เกินไป ลองใช้รูปไม่เกิน 10MB" ไม่ใช้รหัส error
- Empty state ต้องมีภาพประกอบ + ปุ่มชวนทำต่อ
- ทุกหน้า admin มีไม่เกิน **1 ปุ่ม Primary**
- ใช้ภาษาธุรกิจ ไม่ใช้ศัพท์เทคนิค:

| อย่าใช้ (ศัพท์เทคนิค) | ใช้แทน (ภาษาธุรกิจ) |
|---|---|
| Post type | หน้า / บทความ |
| Slug | ชื่อลิงก์ |
| Taxonomy | หมวดหมู่ / แท็ก |
| Widget / Shortcode | ส่วน / Block |
| Permalink | ที่อยู่หน้าเว็บ |
| Taxonomy term | หมวดหมู่ |

- รองรับ Keyboard shortcut + Accessibility (WCAG 2.1 AA)

### ข้อความมาตรฐาน (ตัวอย่าง)
- ลบสำเร็จ: "ลบแล้ว — เลิกทำ"
- บันทึกสำเร็จ: "บันทึกแล้ว" (ไม่ต้อง toast ถ้าอัตโนมัติ)
- รูปใหญ่เกิน: "รูปใหญ่เกินไป ลองใช้รูปไม่เกิน 10MB"
- ชนกัน: "มีคนอื่นแก้หน้านี้อยู่ ต้องการเขียนทับไหม?"

## 4.6 Accessibility (WCAG 2.1 AA) — เกณฑ์บังคับ

- contrast ≥ 4.5:1 (ข้อความปกติ), ≥ 3:1 (ข้อความใหญ่/ไอคอน)
- ใช้คีย์บอร์ดได้ทุกฟังก์ชัน + focus ring ชัดเจน
- ทุก input มี label, ทุก icon button มี `aria-label`
- เคารพ `prefers-reduced-motion`
- ข้อความไทย line-height ≥ 1.6
