# 22 — Checklist สรุป "ทำไมง่ายกว่า WordPress"

- [x] เมนูหลักแค่ 5 รายการ
- [x] แก้ตรงบนหน้าเว็บจริง (WYSIWYG)
- [x] Wizard สร้างเว็บเสร็จใน 3 นาที
- [x] Design Panel แทนการแก้โค้ด — เห็นผลสดทันที
- [x] Undo/Version history — ผู้ใช้ไม่กลัวทำพัง
- [x] SEO, Backup, SSL, Performance ในตัว ไม่ต้องลง plugin
- [x] Command Palette (⌘K) หาอะไรก็เจอ
- [x] AI ช่วยเขียน/ออกแบบ/แปล
- [x] มือถือใช้งานแก้ไขได้จริง (Responsive admin)
- [x] อัปเดตและดูแลให้อัตโนมัติ

## เทียบเคียงทีละด้าน

| ด้าน | WordPress | Lumio |
|---|---|---|
| เมนู admin | 10+ เมนู | 5 เมนู |
| แก้หน้าเว็บ | Preview วนไปมา | แก้บนหน้าเว็บจริง |
| ธีม | แก้ CSS/PHP | Design Panel |
| SEO | ต้องลง plugin | ในตัว + คะแนนสุขภาพเว็บ |
| ความเร็ว | ขึ้นกับ plugin/theme | เร็วโดยค่าเริ่มต้น (Lighthouse ≥ 90) |
| ความปลอดภัย | ขึ้นกับ plugin | Sandbox + RLS + sanitize ในตัว |
| ดูแล server | ต้องดูแลเอง | Managed + auto-update |
| มือถือ | ดูได้ แต่มักแก้ยาก | แก้ได้จริง |
| ย้อนกลับ | ต้องมี plugin | Undo + Version history ในตัว |
